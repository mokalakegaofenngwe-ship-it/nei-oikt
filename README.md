# Nei Oikt promotional website

A responsive, single-page promotional website based on the supplied Nei Oikt / Deriv poster.

## Preview locally
Open `index.html` in a modern browser. For best results, use a local development server.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select your deployment branch and `/ (root)`, then save.

## Customise the call-to-action
The buttons currently point to Deriv's public website (`https://deriv.com/`). Replace those URLs with your approved referral/affiliate URL if you have one. Do not imply guaranteed earnings or risk-free trading.

## Important
This is a promotional landing page, not a trading platform. It does not collect account credentials, deposits, or payment information. Confirm all product, legal, regulatory and affiliate claims with Deriv before publishing.
